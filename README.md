# מעקב הכנסות והוצאות (sf)

מערכת משפחתית למעקב אחרי הכנסות והוצאות. היא כוללת אתר שמותאם לטלפון ואפשר להתקין אותו על מסך הבית (PWA), ושלוחה בימות המשיח לעדכון בשיחת טלפון. אין חיבור לבנק: כל תנועה נרשמת ידנית.

- **כתובת:** `https://smti.uk/sf/`
- **שרת:** Cloudflare Worker בשם `sf`
- **מסד נתונים:** D1. המערכת יושבת בתוך המסד הקיים `drive-pro`, כי בחשבון כבר יש 10 מסדי D1, וזו התקרה בתוכנית החינמית. כל הטבלאות של הפרויקט מתחילות ב-`sf_`, והמיגרציות נרשמות בטבלה `sf_migrations`. לכן הפרויקט לא נוגע בטבלאות של drive-pro (`logs`, `blocked_users`).

## מה יש במערכת

| נושא | פירוט |
|---|---|
| **משתמשים** | אתה ובת הזוג, עם הרשאות זהות. לכל משתמש: שם, מייל (משמש גם לכניסה עם Google), כמה טלפונים (לזיהוי בשלוחה ולכניסה) וסיסמה |
| **חשבונות ומזומן** | חשבונות בנק (בנק, סניף, מספר חשבון, של מי או משותף) וארנק מזומן. היתרה מתעדכנת בכל הכנסה או הוצאה לפי תאריך החיוב. בכל רגע אפשר לעדכן "כמה יש עכשיו", וההפרש נרשם כ"עדכון יתרה" ולא כהכנסה או הוצאה. אפשר גם להעביר כסף בין חשבונות, למשל משיכת מזומן |
| **כסף של אחרים** | כסף שנמצא אצלך אבל לא שלך, עד שיבקשו אותו. משייכים אותו לחשבון שבו הוא נמצא. הוא נשאר בתוך היתרה, ובכל חשבון מוצג כמה ממנו של אחרים, כמה שלך, וכמה חסר להחזיר לשם אם השתמשת בו. רושמים "קיבלתי עוד" ו"החזרתי לו" |
| **לאן הלך הכסף** | דוח מהעסקה הראשונה (לפי התאריך שלה), או מהחודש, מחודש שעבר או מטווח תאריכים. מציג כמה נכנס ויצא, כל קטגוריה עם האחוז שלה (לחיצה פותחת את התנועות), מאיפה הגיעו ההכנסות, איך שולם, של מי וסיכום יום אחר יום. מציג גם כמה כסף זז בלי רישום, לפי ההפרשים שנמצאו בעדכוני יתרה |
| **כרטיסי אשראי** | **דיירקט:** הכסף יורד מהחשבון ביום הקנייה. **רגיל:** כל חיוב בכרטיס יורד מהחשבון ביום החיוב הקרוב. למשל, ביום חיוב 15: חיוב ב-15 יורד באותו יום, וחיוב ב-20 יורד ב-15 בחודש הבא |
| **תנועות** | הוצאה או הכנסה. סכום, תאריך, קטגוריה, אמצעי תשלום (כרטיס, חשבון או מזומן), של מי והערה. תאריך החיוב בחשבון מחושב לבד, ואפשר לשנות אותו ידנית |
| **קבועות** | משכורות, הוראות קבע ומנויים. נקבעים יום בחודש וכל כמה חודשים, לפי תאריך לועזי או **תאריך עברי**, למשל משכורת כולל בא׳ לחודש (ראש חודש). תאריך עברי חוזר כל חודש עברי, ול׳ בחודש של 29 יום נופל על כ״ט. **אוטומטי:** נרשם לבד ביום שלו. **דורש אישור:** מופיע בדף הבית ב"ממתין לאישור" ומאשרים עם הסכום בפועל, כמו משכורת שמשתנה |
| **דף הבית** | סיכום החודש לפי קטגוריות, יתרות בחשבונות, תנועות שממתינות לאישור ומה צפוי ב-30 הימים הקרובים |
| **צפי** | מה ייכנס ומה ייצא מהחשבונות בכל יום, כולל חיובי אשראי על רכישות שכבר נעשו, עם יתרה מצטברת והנקודה הנמוכה ביותר |

אין Cron, כי בתוכנית החינמית מותרות רק 5 משימות מתוזמנות לחשבון. במקום זה התנועות הקבועות נרשמות בכל פעם שמישהו פותח את האתר או מתקשר לשלוחה.

## הקמה (פעם אחת)

1. **הטבלאות:** כבר נוצרו ב-`drive-pro` (מיגרציות `0001` עד `0003`). מיגרציה חדשה מריצים עם `npm run migrate`.
2. **חיבור ה-Worker:** ב-Cloudflare נכנסים ל-Workers & Pages ← Create ← Import a repository ← `smt-ivr/sf`. מעכשיו כל דחיפה ל-`main` נבנית ונפרסת אוטומטית.
3. **ניתוב:** ב-Worker `sf` נכנסים ל-Settings ← Domains & Routes ← Add route, ומוסיפים `smti.uk/sf*` באזור `smti.uk`.
4. **כניסה ראשונה:** נכנסים ל-`https://smti.uk/sf/`. בפעם הראשונה המערכת מבקשת ליצור משתמש וסיסמה, ואחר כך מוסיפים בהגדרות את המשתמש של בת הזוג, את הטלפונים, את חשבונות הבנק ואת הכרטיסים.

## שלוחה בימות המשיח

בהגדרות ← "שלוחה בימות המשיח" מופיע הקישור עם המפתח. מדביקים בקובץ `ext.ini` של שלוחה מסוג API:

```
type=api
api_link=https://smti.uk/sf/api/ivr?key=<המפתח>
api_hangup_send=yes
```

**מהלך השיחה:**
- המתקשר מזוהה לפי מספר הטלפון. מספר שלא מחובר לאף משתמש נחסם.
- **1:** הוספת הוצאה. **2:** הוספת הכנסה. בשניהם: מקישים סכום בשקלים ואז סולמית, בוחרים קטגוריה, בוחרים אמצעי תשלום (כרטיסים, חשבונות בנק, 0 למזומן שנרשם בארנק) ומאשרים.
- **3:** מצב החודש: כמה נכנס, כמה יצא, היתרה בבנק ובמזומן, כמה מזה של אחרים ומה צפוי בשבוע הקרוב.
- **0:** סיום.
- אחרי כל פעולה חוזרים לתפריט, כך שאפשר להזין כמה תנועות בשיחה אחת.

סדר הקטגוריות בתפריט הטלפוני נקבע לפי השדה "סדר" שבהגדרות הקטגוריה.

## פיתוח

```bash
npm test          # בדיקות שרת (node:sqlite במקום D1, בלי רשת)
npm run dev       # wrangler dev מקומי
```

**מבנה התיקיות:**
- `api/src`: ה-Worker. הקובץ `money.js` מחשב יתרות, צפי ותנועות קבועות. הקובץ `dates.js` מחשב תאריכי חיוב ומופעים. הקובץ `ivr.js` מטפל בשלוחה. ההתחברות והניהול נמצאים בתיקייה `routes/`.
- `api/migrations`: הטבלאות, כולן עם הקידומת `sf_`.
- `web`: הממשק, בנוי ב-Preact ו-htm בלי שלב בנייה.

**כללים:**
- סכומים נשמרים באגורות, כמספר שלם.
- תאריכים נשמרים כ-`YYYY-MM-DD` לפי שעון ישראל.
